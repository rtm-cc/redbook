### External Code & Web Engines

- [Grep.app](https://grep.app/) — Fast, exact-match regex search across open-source code.
- [PublicWWW](https://publicwww.com/) — Source code search engine for front-end assets, HTML, and site headers.
- [SearchCode](https://searchcode.com/) — Multi-platform code search across public repositories.
- [Sourcegraph](https://sourcegraph.com/search) — Advanced regex and structural code search across millions of repositories.
- [GitLab Global Search](https://gitlab.com/search) — Public repository code search on GitLab.
